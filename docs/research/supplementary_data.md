## 3. Weapon & Staff Data

*(Referencing Tables 8.2a-f and 8.3 from the original source documents)*
*Note: Comprehensive tables with Mt, Hit, Crit, Wt, Rng, Uses, Rank, Worth, and Effects for every weapon and staff should be referenced from dedicated database sources like Serenes Forest pages linked in the original documents.*

**Key Data Points Summary:**
- **Weapon Ranks:** E, D, C, B, A, * (Personal)
- **Ranges:** 1 (Melee), 2 (Ranged), 1-2 (Versatile), 3-10 / 3-15 (Siege)
- **Effectiveness:** x3 Might multiplier (e.g., Armorslayer vs Armor, Bows vs Fliers, Rapier vs Armor/Cav).
- **Brave Effect:** Allows 2 consecutive hits per attack initiation (e.g., Brave Sword, Hero Axe, Master Lance, Dime Thunder).
- **Magic Swords:** Deal magic damage at range 2 (e.g., Light Brand, Flame Sword).
- **Status Weapons:** Inflict Poison, Sleep, Berserk.
- **Personal Weapons ('*'):** Usable only by specific characters, often with unique effects (e.g., Pugi, Grafcalibur, Light Brand).
- **Staff Accuracy:** 60% Base + (4 * Skl), capped 1-99%. Torch staff 100% Base.
- **Status Staff Condition:** User Mag > Target Mag required for Sleep, Silence, Berserk, Thief staves. Fails on Throne/Gate targets.
- **Staff EXP:** Varies per staff (e.g., Live=15, Relive=17, Warp=40, Repair=30).

### 5.2. EXP Formula Components

*   **Combat EXP (Base):** `(31 - Unit Level) / Unit Class Power`
*   **Defeat EXP Bonus:** `{Class Bonus + 20 - (Enemy Level - Unit Level) * (Class Bonus / 4 + 8)} + Base Combat EXP + Boss Bonus + Thief Bonus`
    *   `Class Bonus`: 0 for base, 20 for promoted.
    *   `Boss Bonus`: +40 if enemy is chapter boss.
    *   `Thief Bonus`: +20 if enemy has Steal skill.
    *   Result cannot be negative.
*   **(Note:** Exact 'Unit Class Power' values are not provided in the source documents but are needed for implementation. They generally reflect class tier.)*

### 5.4. Support Bonuses Data

*   **Range:** 3 tiles radius.
*   **Standard Bonus:** +10 Hit, +10 Avoid, +10 Crit, +10 Crit Evade.
*   **Special Bonus:** Some pairs grant +20 instead (e.g., Mareeta support from Galzus).
*   **Stacking:** Bonuses stack up to a maximum of +30 total from supports.
*   **Directionality:** Supports are often one-way (A supports B, but B doesn't support A). Some are mutual.

### 5.5. Reinforcement Data Structure

*   Reinforcements are typically defined per chapter with the following parameters:
    *   **Chapter:** The chapter number.
    *   **Trigger:** Condition for spawning (e.g., Turn Number range, entering a map Zone, specific event).
    *   **Class:** Enemy class type.
    *   **Level:** Enemy level.
    *   **Spawn Location:** Coordinates or designated area (e.g., Forts, Map Edge).
    *   **Quantity:** Number of units spawning per trigger instance.
    *   **Inventory:** Items/weapons carried by the spawned unit.
    *   **AI Behavior:** Default stance (e.g., Charge, Guard).
    *   **Notes:** Any special conditions (e.g., Random chance, acts immediately).
