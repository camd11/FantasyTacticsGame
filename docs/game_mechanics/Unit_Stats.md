# Thracia 776: Unit Statistics Specification\n\nThis document details primary and derived unit stats, along with special traits in Fire Emblem: Thracia 776.\n\n## 1. Primary Stats\n\nThese are the core stats defining a unit\'s capabilities. They increase via level-ups based on character growth rates.\n\n-   **HP (Hit Points):** Unit health. Reaching 0 results in permadeath (or Game Over for Leif).\n    -   *Max Cap:* 80\n-   **Str (Strength):** Increases physical damage (Swords, Lances, Axes, Bows).\n    -   *Max Cap:* 20\n-   **Mag (Magic):** Increases magical damage (Tomes, Magic Swords at range 2). Also acts as magical defense.\ Used for status staff checks.\n    -   *Max Cap:* 20\n-   **Skl (Skill):** Affects Hit Rate, Critical Rate, Staff Accuracy, and activation rate of %Skills (Luna, Sol, Astra, Adept).\n    -   *Max Cap:* 20\n-   **Spd (Speed):** Affects Avoidance, Attack Speed (AS) for doubling, and Steal command eligibility.\n    -   *Max Cap:* 20\n-   **Lck (Luck):** Minorly affects Hit/Avoid (+1 per point). Reduces enemy critical chance (CEv = Lck/2). Affects Miracle activation, Devil Axe backfire.\n    -   *Max Cap:* 20\n-   **Def (Defense):** Reduces damage taken from physical attacks.\n    -   *Max Cap:* 20\n-   **Bld (Build / Constitution):** Mitigates AS penalty from physical weapon Weight. Determines Rescue/Capture ability. Affects Stealing heavier items.\n    -   *Max Cap:* 20\n-   **Mov (Movement):** Base tiles movable on standard terrain.\n    -   *Max Cap:* 20\n\n## 2. Derived Stats\n\nCalculated from primary stats, equipment, and other factors.\n\n-   **Attack (Atk):**\n    -   Physical: `Str + Weapon Might`\n    -   Magical: `Mag + Tome Might`\n    -   *Effectiveness triples Might (x3)*\n-   **Attack Speed (AS):**
    -   For All Weapons: `Spd - MAX(0, Weapon Weight - Bld)`
    -   *Note: This is a custom implementation that deviates from Thracia 776. Build/Con mitigates weight penalty for all weapon types, including tomes.*
-   **Hit Rate:** `(Wpn Hit + (Skl*2) + Lck + Supports + LS + Charisma + Triangle) - Target Avoid`. (Capped 1-99%)\n-   **Avoid (Avo):** `(AS*2) + Lck + Supports + LS + Charisma + Terrain Bonus`.\n-   **Critical Rate (Crit %):** `(Wpn Crit + Skl + Supports) - Target Crit Evade`.\n    -   *First hit capped at 25% (unless Wrath)*.\n    -   *Follow-up hits use PCC: `Crit Rate * PCC` (no 25% cap)*.\n-   **Crit Evade (CEv):** `(Target Lck / 2) + Support Bonus`. (Scrolls negate non-Wrath crits).\n-   **Physical Defense:** `Def + Terrain Def Bonus`.\n-   **Magical Defense:** `Mag + Terrain Def Bonus`.\n\n## 3. Special Stats & Traits\n\n-   **Leadership Stars (LS / ★):** (0-5 stars). Each star from deployed leaders grants +3 Hit/Avo globally to allies. Stacks.\n-   **Movement Stars (MS / ♪):** (0-5 stars). Grants `(5 * MS)%` chance for a second action after the first.\n-   **Fatigue:** Hidden counter. Increases with actions. If `Fatigue > Max HP` at chapter end, unit cannot deploy next chapter (except Leif / S Drink).\n-   **Pursuit Critical Coefficient (PCC):** (0-5). Multiplies critical rate ONLY on follow-up attacks. PCC=0 means no crits on follow-ups.\n\n*(Refer to `docs/research/New_Stats.md` for character-specific base stats, growths, PCC, LS, MS, and class base/max stats.)*\n
