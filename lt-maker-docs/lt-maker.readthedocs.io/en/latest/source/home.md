# Lex Talionis Wiki<a href="home.html#lex-talionis-wiki" class="headerlink"
title="Link to this heading"></a>

This wiki serves as a helpful additional resource when using
**LT-Maker** and the **Lex Talionis Engine**. If you’ve ever wanted to
create your own Fire Emblem fangame, here’s the place to start.

You can find answers to your questions and a helpful community at the:

<a href="https://discord.gg/dC6VWGh4sw" class="reference external">Lex
Talionis Discord Server</a>
