## Importing Map Sprites<a href="Map-Sprites-Editor.html#importing-map-sprites"
class="headerlink" title="Link to this heading"></a>

LT editor can import map sprites from both GBA format and LT project
format. Doing so will prompt you first for the image of the standing
frames, followed by the image of the moving frames.
