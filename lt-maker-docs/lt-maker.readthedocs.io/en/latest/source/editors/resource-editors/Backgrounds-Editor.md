## Multi-Image Backgrounds<a href="Backgrounds-Editor.html#multi-image-backgrounds"
class="headerlink" title="Link to this heading"></a>

In order to import a multi-image background, place all the images of
that background in the same folder and give the images the same name
with the order number of the image after the name, starting with 0.

For example, if you have 5 images, you can name them
<span class="pre">`image0.png`</span>,
<span class="pre">`image1.png`</span>,
<span class="pre">`image2.png`</span>,
<span class="pre">`image3.png`</span>, and
<span class="pre">`image4.png`</span>.
