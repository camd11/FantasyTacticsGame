# RegionObject class<a href="region-reference.html#regionobject-class" class="headerlink"

*<span class="pre">class</span><span class="w"> </span>*<span class="sig-prename descclassname"><span class="pre">app.engine.objects.region.</span></span><span class="sig-name descname"><span class="pre">RegionObject</span></span><a href="region-reference.html#app.engine.objects.region.RegionObject"

the unchanging Region you created in the level editor.

Inherits from the Region Prefab to access Region’s helper functions like
area and center.
