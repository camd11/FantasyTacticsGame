Parameters<span class="colon">:</span>  
- **unit**
  (<a href="unit-reference.html#app.engine.objects.unit.UnitObject"
  class="reference internal"
  title="app.engine.objects.unit.UnitObject"><em>UnitObject</em></a>) –
  The unit attempting to use the item.

- **item** (*ItemObject*) – The item to check.

- **distance** (*int,* *optional*) – The distance at which the item is
  used. Defaults to 0.

will only be magical while used at a range \> 1.

True if the item is a magic item, False otherwise.
