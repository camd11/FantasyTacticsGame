# UnitObject class<a href="unit-reference.html#unitobject-class" class="headerlink"
title="Link to this heading"></a>

*<span class="pre">class</span><span class="w"> </span>*<span class="sig-prename descclassname"><span class="pre">app.engine.objects.unit.</span></span><span class="sig-name descname"><span class="pre">UnitObject</span></span><a href="unit-reference.html#app.engine.objects.unit.UnitObject"
class="headerlink" title="Link to this definition"></a>  
A unit. The entities that can move around on the map, attack, be
attacked, etc.

Units have name IDs (or NIDs) that uniquely identify them. The remaining
attributes and methods of UnitObjects are described below.

<span class="sig-name descname"><span class="pre">nid</span></span>*<span class="p"><span class="pre">:</span></span><span class="w"> </span><span class="pre">str</span>*<a href="unit-reference.html#app.engine.objects.unit.UnitObject.nid"
class="headerlink" title="Link to this definition"></a>  
Unique identifier

<span class="sig-name descname"><span class="pre">prefab_nid</span></span>*<span class="p"><span class="pre">:</span></span><span class="w"> </span><span class="pre">str</span><span class="w"> </span><span class="p"><span class="pre">=</span></span><span class="w"> </span><span class="pre">None</span>*<a
href="unit-reference.html#app.engine.objects.unit.UnitObject.prefab_nid"
class="headerlink" title="Link to this definition"></a>  
NID of this unit’s prefab (usually the same as it’s *nid*)

<span class="sig-name descname"><span class="pre">generic</span></span>*<span class="p"><span class="pre">:</span></span><span class="w"> </span><span class="pre">bool</span><span class="w"> </span><span class="p"><span class="pre">=</span></span><span class="w"> </span><span class="pre">False</span>*<a href="unit-reference.html#app.engine.objects.unit.UnitObject.generic"
class="headerlink" title="Link to this definition"></a>  
Whether the unit is a generic

<span class="sig-name descname"><span class="pre">persistent</span></span>*<span class="p"><span class="pre">:</span></span><span class="w"> </span><span class="pre">bool</span><span class="w"> </span><span class="p"><span class="pre">=</span></span><span class="w"> </span><span class="pre">True</span>*<a
href="unit-reference.html#app.engine.objects.unit.UnitObject.persistent"
class="headerlink" title="Link to this definition"></a>  
If unit is persistent, unit will not be removed between levels. Generic
units start off without persistence.

<span class="sig-name descname"><span class="pre">ai</span></span>*<span class="p"><span class="pre">:</span></span><span class="w"> </span><span class="pre">str</span><span class="w"> </span><span class="p"><span class="pre">=</span></span><span class="w"> </span><span class="pre">None</span>*<a href="unit-reference.html#app.engine.objects.unit.UnitObject.ai"

<span class="sig-name descname"><span class="pre">ai_group</span></span>*<span class="p"><span class="pre">:</span></span><span class="w"> </span><span class="pre">str</span><span class="w"> </span><span class="p"><span class="pre">=</span></span><span class="w"> </span><span class="pre">None</span>*<a

<span class="sig-name descname"><span class="pre">roam_ai</span></span>*<span class="p"><span class="pre">:</span></span><span class="w"> </span><span class="pre">str</span><span class="w"> </span><span class="p"><span class="pre">=</span></span><span class="w"> </span><span class="pre">None</span>*<a href="unit-reference.html#app.engine.objects.unit.UnitObject.roam_ai"
class="headerlink" title="Link to this definition"></a>

<span class="sig-name descname"><span class="pre">faction</span></span>*<span class="p"><span class="pre">:</span></span><span class="w"> </span><span class="pre">str</span><span class="w"> </span><span class="p"><span class="pre">=</span></span><span class="w"> </span><span class="pre">None</span>*<a href="unit-reference.html#app.engine.objects.unit.UnitObject.faction"

<span class="sig-name descname"><span class="pre">team</span></span>*<span class="p"><span class="pre">:</span></span><span class="w"> </span><span class="pre">str</span><span class="w"> </span><span class="p"><span class="pre">=</span></span><span class="w"> </span><span class="pre">'player'</span>*<a href="unit-reference.html#app.engine.objects.unit.UnitObject.team"
class="headerlink" title="Link to this definition"></a>

<span class="sig-name descname"><span class="pre">portrait_nid</span></span>*<span class="p"><span class="pre">:</span></span><span class="w"> </span><span class="pre">str</span><span class="w"> </span><span class="p"><span class="pre">=</span></span><span class="w"> </span><span class="pre">None</span>*<a

<span class="sig-name descname"><span class="pre">affinity</span></span>*<span class="p"><span class="pre">:</span></span><span class="w"> </span><span class="pre">str</span><span class="w"> </span><span class="p"><span class="pre">=</span></span><span class="w"> </span><span class="pre">None</span>*<a
